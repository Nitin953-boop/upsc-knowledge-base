# UPSC NoteMaker Ultimate V11

A clean-sheet professional writing/document-editor build based on the supplied V7.4 Android project.

## Editor
- Word-style Home / Insert / Draw / Layout / View ribbon
- Long-form writing canvas with A4 page boundaries and continuous view
- Typography, styles, headings, alignment, lists, indentation, colours and highlighting
- Undo / redo
- Search, replace and table of contents
- Footnotes and cross-references
- Inline Updates
- Tables starting at 10/20/30/40/50 rows and unlimited row/column additions
- Free-position images, video, audio and file objects
- Object resize, move, rotate and delete
- No filename captions under images/video
- Sticky notes that can be edited, moved and deleted
- Pen, highlighter and eraser with persisted drawing strokes
- Manual page breaks when actually desired
- Reading mode
- Print / PDF and Word-compatible export
- Local-first IndexedDB document storage
- Android attachment storage up to 100 MB per file
- GitHub Actions APK build

## Build
GitHub Actions builds `app-debug.apk` and publishes the artifact:
`UPSC-NoteMaker-Ultimate-V11-APK`.
